Infraestructura Cloud

Conexión y Sincronización con Supabase

Conecta tu proyecto de Supabase para respaldar y sincronizar en la nube todas las secciones dinámicas (visibilidad, videos del hero, barra de logos, servicios, industrias, proyectos, protocolo y comentarios). Ejecuta primero supabase/schema.sql en el SQL Editor de Supabase.

Flujo de Sincronización Bidireccional Activo:

• Al conectar la Project URL y las llaves, la página principal (GET /api/cms) carga toda la información directamente desde las tablas de Supabase.

• Cada vez que presionas Guardar en cualquier pestaña de este panel (POST /api/cms), los cambios (incluyendo nuevos elementos, ediciones, tags o eliminaciones) se actualizan automáticamente en Supabase.
